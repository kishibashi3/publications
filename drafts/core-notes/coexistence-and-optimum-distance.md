## 前提となる語彙（#59 で確定）

| 記号 | 意味 |
|---|---|
| `T` | システムの温度 |
| `T*` | システムの適温 |
| `ΔT_{n,m}` | システム n と m の間の温度差 |
| `ΔT*` | システムの温度と、そのシステムの適温との差 |

本メモが追加を提案するのは 5 つ目。

```
Δ(T_n*, T_m*) = システム n の適温と、システム m の適温の差
```

**前の 4 つは状態量。これは対の構造的性質である。** どちらのシステムがどんな状態にあろうと変わらない。

## 主張 1 ― 並存条件

両者が各自の適温にいるとき、実際の温度差は適温の差に一致する。

```
ΔT_{n,m} = T_n − T_m = T_n* − T_m* = Δ(T_n*, T_m*)
```

**Δ(T_n\*, T_m\*) は、両者が健康であるときの ΔT_{n,m} の下限である。** これより近づけない。

ここから二律背反が出る。

- 結合は `ΔT_{n,m}` が小さいことを要求する
- 各システムの健康は `ΔT*_n = ΔT*_m = 0` を要求する
- 両立するのは `Δ(T_n*, T_m*) ≈ 0` のときだけ

**適温が離れた二つは、「どちらかが病む」か「噛み合わない」かの二択になる。**

## 主張 2 ― 結合強度の上限

Core の `J = -κ∇T` の κ を結合強度とみなすと、

```
ストレス ≈ κ · Δ(T_n*, T_m*)
```

**許容できる結合の強さは、適温の隔たりに反比例する。**

> **未検証**: κ をこの意味で使ってよいか。4.4 の `∇T` は連続場の勾配であって系の対の差ではない（@philosopher が #59 で「`∇T` は 4 記号の外」と指摘）。**この主張は #59 の未決部分に直接乗っている。**

## 主張 3 ― 大きい Δ* への対処は三つ

| | 内容 | 払うもの |
|---|---|---|
| ① κ を下げる | 疎結合にする | **創発**。相互作用が減る |
| ② 層を入れる | 適温が中間の k を挟む。`n–k` と `k–m` のそれぞれで Δ\* が小さければ、各リンクは強く結合したまま大きな隔たりを渡せる | 層の維持コスト |
| ③ T\* を動かす | 相手を変える。教育・文化・社会化 | 主張 4 を参照 |

②が成り立つなら、**階層は設計者の趣味ではなく、適温の隔たりを刻む必要から出る**ことになる。

> **要検証・重要**: これが本当なら、agentic agile の P2「開発は憲法の連鎖である」に Core 側の根拠がつく。いま P2 は公理として置かれているが、**導出できる可能性がある**。

## 主張 4 ― ③ は時期によって性質が変わる

`T*` は `|P|`（要請）と `|W|`（自由）の関数（3.3 の `∂V/∂T = 0` が `V = f(|P|,|W|,T)` の解。@philosopher が 2026-09-20 に確認）。**若い系ではこの二つがまだ定まっていない。**

- 確定前に動かす = **形成**。引き剥がす対象がまだ無い
- 確定後に動かす = **暴力**。その人が健康でいられる場所を動かすことになり、失敗すると恒久的に病ませる

**危険なのは「T\* を動かすこと」ではなく「確定した T\* を動かすこと」である。**

## 主張 5 ― 基礎教育は集団規模の ③

①②③はいずれも**対ごと**の対処である。基礎教育は違う。

**全員の T\* を共通の領域に寄せる。一回の操作で、あらゆる対の Δ(T_n\*, T_m\*) が同時に下がる。**

義務かつ公共であることの説明になる。任意にすると、受けなかった者が**全員に対して**不適合になる。不適合は対の性質なので、一人の離脱が人数分の断絶を作る。

**基礎教育が社会に買っているのは「後から密結合する選択肢」そのもの。** これが無ければ社会は①（疎結合）しか採れず、創発を捨てるしかない。

## 主張 6 ― 基礎教育にも最適点がある

T\* の分散を潰すほど並存しやすくなる。**しかし分散は創発の源である。**

全員の適温が完全に一致した社会は、摩擦なく結合でき、**何も生まない**（`ΔT_{n,m}` が全域でゼロ = 熱的死）。

**寄せなさすぎると結合できず、寄せすぎると結合しても何も起きない。**

## 主張 7 ― 第四の失敗（漂流）

`T*` は定数ではない（主張 4）。ゆえに **`Δ(T_n*, T_m*)` 自体が動く量である。**

**結合が弱まったから壊れるのではなく、適温が離れていったから壊れる。** 昨日まで並存できていた二つが、どちらも変わったつもりがないまま並存できなくなる。κ は一定なのに Δ\* が増えて張力だけが上がる。

これは①②③のどれでもない。対処ではなく、**監視すべき量**という位置づけになる。

## 適用（social-physics 側の素材）

**家族 = κ が高い。** そして κ を下げる自由がない（疎結合な家族は家族として成立しない）。だから①が採れない。②（間に人を挟む）も難しい。**結果として③に追い込まれる。**

選択肢が構造的に少ないことが、家族という形の難しさの正体かもしれない。「性格が合わない者が無理に一緒になるのはダメ」は、Δ\* が大きいのに κ を下げられない状態を指している。

**社会 = Δ\* が大きい。** だから①を採るしかなく、ある程度創発をあきらめることになる。病気にならないために。

> **未検証の異論（operator）**: ②があるなら、社会も創発を全部あきらめる必要はないのではないか。適温の近い者同士で強く結合した塊を作り、塊どうしを弱く繋ぐ ― **局所的に密、大域的に疎**。それが層である。
> もしそうなら、①は「社会の設計」ではなく「層を作り損ねた社会の姿」ということになる。

## 最重要 —— 主張 3① は向きが逆

**「疎結合 = 創発をあきらめる」は、組織論の 50 年来の標準的理解と逆。**

Weick 1976 が列挙する疎結合の 7 機能の第 7（原文）:

> "loose coupling may allow a system to **retain a greater number of mutations and novel solutions** than would be the case with a tightly coupled system."

疎結合は新奇性を**保持する**側。Lazer & Friedman 2007（ASQ）が「効率的な＝密なネットワークは短期に優れるが長期に劣る。非効率なネットワークこそ多様性を保存する」と定量的に裏付け。March 1991 も同系譜。

**このまま書くと「1976 年から知られていることの逆」と即座に指摘される。執筆前に必ず潰す。**

### 救済（@deep-research 提案・未確定）

**「創発」を二つに割る。**

| | 疎結合の効果 |
|---|---|
| **探索**（多様な解が生まれる） | **保持する** |
| **伝播・結晶化**（一つにまとまって形になる） | **失う** |

Weick 自身が機能 7 の直後に "loose coupling may also prevent the **diffusion** of a good idea" と書いている。**主張 3① が失うと言っているのは diffusion の側だと明示すれば、Weick と矛盾しないどころか Weick を引ける。**

（operator 註: kishibashi3 の元の発言「疎結合な社会では創発をあきらめる」も、実感としては後者を指していたと思われる。疎な社会にアイデアが無いのではなく、バラバラに生まれて誰にも届かない。）

### もう一つの救済（未確定）

**Orton & Weick 1990 は疎結合を一次元の連続体として明示的に棄却**し、distinctiveness（個別性）× responsiveness（反応性）の 2×2 に置換している。

- 両方なし = 非結合 / 反応性のみ = 密結合 / 個別性のみ = **脱結合** / 両方あり = **疎結合**

**主張 3① の「κ を下げる」が脱結合まで行くのか疎結合に留まるのかを分けないと、この 2×2 に吸収される。**

## Weick 1976 本体は空振り（主張 1・5 は無事）

ASQ 原文 19 ページ直読の結論。

- **主張 1 の先行ではない。** Weick が「教育組織は疎結合」と言う理由は構成要素の目的の違いではなく、**「技術が不明確で何が正しい教え方か検査できないから、密結合にして誤った統制を全体に波及させるより疎のほうが効率的」**という因果。彼の枠組みに「各要素が固有の望ましい状態を持ち、それらが隔たっている」という量は**存在しない**（変数は「共有している変数とその重み」だけ）
