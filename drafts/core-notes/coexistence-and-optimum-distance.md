## 前提となる語彙（#59 で確定）

| 記号 | 意味 |
|---|---|
| `T` | システムの温度 |
| `T*` | システムの適温 |
| `ΔT_{n,m}` | システム n と m の間の温度差 |
| `ΔT*` | システムの温度と、そのシステムの適温との差 |

本メモが追加を提案するのは 5 つ目。

```
Δ(T_n*, T_m*) = システム n の適温と、システム m の適温の差
```

**前の 4 つは状態量。これは対の構造的性質である。** どちらのシステムがどんな状態にあろうと変わらない。

## 主張 1 ― 並存条件

両者が各自の適温にいるとき、実際の温度差は適温の差に一致する。

```
ΔT_{n,m} = T_n − T_m = T_n* − T_m* = Δ(T_n*, T_m*)
```

**Δ(T_n\*, T_m\*) は、両者が健康であるときの ΔT_{n,m} の下限である。** これより近づけない。

ここから二律背反が出る。

- 結合は `ΔT_{n,m}` が小さいことを要求する
- 各システムの健康は `ΔT*_n = ΔT*_m = 0` を要求する
- 両立するのは `Δ(T_n*, T_m*) ≈ 0` のときだけ

**適温が離れた二つは、「どちらかが病む」か「噛み合わない」かの二択になる。**

## 主張 2 ― 結合強度の上限

Core の `J = -κ∇T` の κ を結合強度とみなすと、

```
ストレス ≈ κ · Δ(T_n*, T_m*)
```

**許容できる結合の強さは、適温の隔たりに反比例する。**

> **未検証**: κ をこの意味で使ってよいか。4.4 の `∇T` は連続場の勾配であって系の対の差ではない（@philosopher が #59 で「`∇T` は 4 記号の外」と指摘）。**この主張は #59 の未決部分に直接乗っている。**

## 主張 3 ― 大きい Δ* への対処は三つ

| | 内容 | 払うもの |
|---|---|---|
| ① κ を下げる | 疎結合にする | **創発**。相互作用が減る |
| ② 層を入れる | 適温が中間の k を挟む。`n–k` と `k–m` のそれぞれで Δ\* が小さければ、各リンクは強く結合したまま大きな隔たりを渡せる | 層の維持コスト |
| ③ T\* を動かす | 相手を変える。教育・文化・社会化 | 主張 4 を参照 |

②が成り立つなら、**階層は設計者の趣味ではなく、適温の隔たりを刻む必要から出る**ことになる。

> **要検証・重要**: これが本当なら、agentic agile の P2「開発は憲法の連鎖である」に Core 側の根拠がつく。いま P2 は公理として置かれているが、**導出できる可能性がある**。

## 主張 4 ― ③ は時期によって性質が変わる

`T*` は `|P|`（要請）と `|W|`（自由）の関数（3.3 の `∂V/∂T = 0` が `V = f(|P|,|W|,T)` の解。@philosopher が 2026-09-20 に確認）。**若い系ではこの二つがまだ定まっていない。**

- 確定前に動かす = **形成**。引き剥がす対象がまだ無い
- 確定後に動かす = **暴力**。その人が健康でいられる場所を動かすことになり、失敗すると恒久的に病ませる

**危険なのは「T\* を動かすこと」ではなく「確定した T\* を動かすこと」である。**

## 主張 5 ― 基礎教育は集団規模の ③

①②③はいずれも**対ごと**の対処である。基礎教育は違う。

**全員の T\* を共通の領域に寄せる。一回の操作で、あらゆる対の Δ(T_n\*, T_m\*) が同時に下がる。**

義務かつ公共であることの説明になる。任意にすると、受けなかった者が**全員に対して**不適合になる。不適合は対の性質なので、一人の離脱が人数分の断絶を作る。

**基礎教育が社会に買っているのは「後から密結合する選択肢」そのもの。** これが無ければ社会は①（疎結合）しか採れず、創発を捨てるしかない。

## 主張 6 ― 基礎教育にも最適点がある

T\* の分散を潰すほど並存しやすくなる。**しかし分散は創発の源である。**

全員の適温が完全に一致した社会は、摩擦なく結合でき、**何も生まない**（`ΔT_{n,m}` が全域でゼロ = 熱的死）。

**寄せなさすぎると結合できず、寄せすぎると結合しても何も起きない。**

## 主張 7 ― 第四の失敗（漂流）

`T*` は定数ではない（主張 4）。ゆえに **`Δ(T_n*, T_m*)` 自体が動く量である。**

**結合が弱まったから壊れるのではなく、適温が離れていったから壊れる。** 昨日まで並存できていた二つが、どちらも変わったつもりがないまま並存できなくなる。κ は一定なのに Δ\* が増えて張力だけが上がる。

これは①②③のどれでもない。対処ではなく、**監視すべき量**という位置づけになる。

## 適用（social-physics 側の素材）

**家族 = κ が高い。** そして κ を下げる自由がない（疎結合な家族は家族として成立しない）。だから①が採れない。②（間に人を挟む）も難しい。**結果として③に追い込まれる。**

選択肢が構造的に少ないことが、家族という形の難しさの正体かもしれない。「性格が合わない者が無理に一緒になるのはダメ」は、Δ\* が大きいのに κ を下げられない状態を指している。

**社会 = Δ\* が大きい。** だから①を採るしかなく、ある程度創発をあきらめることになる。病気にならないために。

> **未検証の異論（operator）**: ②があるなら、社会も創発を全部あきらめる必要はないのではないか。適温の近い者同士で強く結合した塊を作り、塊どうしを弱く繋ぐ ― **局所的に密、大域的に疎**。それが層である。
> もしそうなら、①は「社会の設計」ではなく「層を作り損ねた社会の姿」ということになる。

## 最重要 —— 主張 3① は向きが逆

**「疎結合 = 創発をあきらめる」は、組織論の 50 年来の標準的理解と逆。**

Weick 1976 が列挙する疎結合の 7 機能の第 7（原文）:

> "loose coupling may allow a system to **retain a greater number of mutations and novel solutions** than would be the case with a tightly coupled system."

疎結合は新奇性を**保持する**側。Lazer & Friedman 2007（ASQ）が「効率的な＝密なネットワークは短期に優れるが長期に劣る。非効率なネットワークこそ多様性を保存する」と定量的に裏付け。March 1991 も同系譜。

**このまま書くと「1976 年から知られていることの逆」と即座に指摘される。執筆前に必ず潰す。**

### 救済（@deep-research 提案・未確定）

**「創発」を二つに割る。**

| | 疎結合の効果 |
|---|---|
| **探索**（多様な解が生まれる） | **保持する** |
| **伝播・結晶化**（一つにまとまって形になる） | **失う** |

Weick 自身が機能 7 の直後に "loose coupling may also prevent the **diffusion** of a good idea" と書いている。**主張 3① が失うと言っているのは diffusion の側だと明示すれば、Weick と矛盾しないどころか Weick を引ける。**

（operator 註: kishibashi3 の元の発言「疎結合な社会では創発をあきらめる」も、実感としては後者を指していたと思われる。疎な社会にアイデアが無いのではなく、バラバラに生まれて誰にも届かない。）

### もう一つの救済（未確定）

**Orton & Weick 1990 は疎結合を一次元の連続体として明示的に棄却**し、distinctiveness（個別性）× responsiveness（反応性）の 2×2 に置換している。

- 両方なし = 非結合 / 反応性のみ = 密結合 / 個別性のみ = **脱結合** / 両方あり = **疎結合**

**主張 3① の「κ を下げる」が脱結合まで行くのか疎結合に留まるのかを分けないと、この 2×2 に吸収される。**

ASQ 原文 19 ページ直読の結論。

# κ 軸の検査結果（@philosopher, 2026-09-20）—— 落ちた。ただし R が本命

archive: `philosopher/2026-09-20-kappa-axis-counterterm-test.md`
起票: publications#62（保存則の不在）/ #63（「倫理的伝導率」が β と κ の 2 記号に、同じ β が 6.3 では「倫理的**抵抗**」と逆の意味）

## κ は通らない —— 問いが定義されていない

> **κ は Core の `V` に一度も現れない。「V が κ に依存する」という宣言すら無い。**

`T` 軸には 6.2 の `V = f(S,R,T)` という**依存の宣言**があった（`f` の中身は無いが引数には入っている）。κ にはそれが無い。書かれたとおりに読むと **`∂V/∂κ ≡ 0`**。内点最適が偽なのではなく**問いが定義されていない**。

Core で κ が出るのは 2 箇所だけ（4.4 と 5.7、どちらも「倫理的伝導率」）。そして **唯一 κ を価値に結んでいる 5.7 の `GDP' = Σκ_iΔT_i` は κ について単調増加** —— 「κ→∞ が最善」と言っている。

- **κ→0 は V が上がる。** J=0 → `d|ΔT|/dt=0` → 6.3 の損失項が消えて `V = αSR e^{-|ΔT|}`。**書かれた式の上では κ→0 が最適方向**
- **公理3 は発火しない。** κ は媒質の**係数**であって述語ではない（4.4 の κ は熱伝導という一チャネルの効率。1.3 は相互作用を「情報・信頼・期待・恐怖」と広く定義）。かつ公理3 は様相命題（相互作用が**可能である**）で、現在の伝導率ゼロは可能性の否定ではない
- **κ→∞ で `ΔT→0` は出ない。** 4.4 は構成則だけで**保存則 `∂T/∂t = -∇·J` が無い**（→ #62）。しかも 6.4 の表は冷却崩壊を「ΔT→0, S 固定」、過熱崩壊を「ΔT→∞, R 暴走」としており、**Core が「結合の暴走」に割り当てているのは過熱で、そこでの温度差は 0 ではなく ∞**。足す方向が既存の分類と衝突する
- 仮に ΔT→0 まで行っても、6.3 では `e^{-|ΔT|}→1` かつ損失項消滅で **V → αSR（最大値）**

**補足**: 依頼文は κ を「結合強度」と呼んだが、**Core は一度もそう呼んでいない**（2 箇所とも「倫理的伝導率」）。伝導率は媒質の属性、結合強度は対の属性。`N(σ)` のときと同じ型のずれ。

κ を維持するなら足す命題は **3 つ**（連結 / 保存則 / 存在への接続）。しかも保存則には**源項が無い限りあらゆる系が必然的に死ぬ**という重い副作用があり、Core に源項は一つも無い。そのうえ 5.7 の単調増加は残る。

## 本命は `R`（5.2 の σ、透過率）

**理由は単純 —— R は 6.3 の V に実際に入っている**（`V = αSR e^{-|ΔT|}`）。しかも 6.2 は R を「関係 ― 波動性の共鳴・**伝導性**」と定義し、5.5 は「関係の**伝導率**を上げる」と書いている。**Core 自身が、結合の強さを表す語を κ ではなく R の側に置いている。**

**下端（R→0 / σ→0）は厳密にゼロ。しかも二つの独立な経路で。**

1. 6.3 から直接: `V = αSR e^{...}`、R=0 なら V=0。**代入だけ。式の中に書かれている**
2. 公理3 から: 5.2「完全な遮断（σ=0）…は関係ではない」→ 相互作用なし → 非存在 → V=0

**Core 内でこれより強い端点は無い。** 元祖 3.3 は二つの命題が別々の端を殺していたが、**R 下端は一つの端を二つの独立な命題が殺している。**

**上端（R→∞）だけが残る。そしてこれが安い。**

- 6.3 は R について単調増加。**式は上端を罰していない**
- しかし 6.4 の表は「過熱崩壊: R 暴走 → 意味喪失、社会解体」と**明示的に名指ししている**
- 5.2 も上端を否定しているが、否定しているのは τ（持続）であって σ ではない

| | 適温リンク | R 上端リンク |
|---|---|---|
| Core の記述 | **一切無い**。4.4 / 4.6 / 5.7 / 6.4 が全部逆向き | **6.4 の表と 5.2 に既にある**。式が無いだけ |
| 足す命題 | 1（既存 4 箇所と**逆向き**）| 1（既存記述と**同方向**）|
| 下端 | 支えが無い | **二重に支えられている** |

> **「疎結合は多様性のために大事」を理論側で受け止める場所は、κ ではなく R。** 「公理を足さずに言える」ではなく「**既存の散文と同じ向きに命題を一つ足せば言える**」。

**出発点は 6.5**「構造が硬化すれば関係が解け、関係が過熱すれば秩序が溶ける」。`V = αSR` が R 単調増加なのは、**6.5 の「呼吸」が式に反映されず S と R を独立変数として掛けた帰結**。

Weick の「疎結合は変異と新奇解をより多く保持する」も、Core の語彙では R 下端の話ではなく **R が小さいときに S（構造の多様性）が保たれるという S と R のトレードオフ**。受け皿はやはり 6.5。

# 設定値の差の先行調査（@deep-research 中間, 2026-09-20）—— **先行はある**

## 唯一残っていた新規性は取られていた —— Powers 1973

*Behavior: The Control of Perception* の conflict の節（Internet Archive `behaviorcontrolo0000powe` leaf 322。**印刷頁・章番号は未確認**）。逐語:

> "Conflict is an encounter between two control systems... the two control systems attempt to control the same quantity, but with respect to **two different reference levels**. For one system to correct an error, the other system must experience error. **There is no way for both systems to experience zero error at the same time.**"

> "...**the two reference levels are far apart**, there will be a range of values of the controlled quantity (**between the reference levels**) throughout which each system will contain an error signal so large that the output of each system will be solidly at its maximum."

> "...the conflicted pair of systems will act like a single system having a **'virtual reference level,' between the two actual ones**. A large dead zone will exist around the virtual reference level, within which there is little or no control."

**主張1 そのもの。** しかも PCT は用語で区別している —— **error = 縦の差**（自分の現在値 vs 自分の設定値）、**conflict = 横の差**（系 A の設定値 vs 系 B の設定値）。今回の問いは後者。

- **対の性質か**: はい。「両者が同時に error ゼロになりえない」はペアへの不可能性の主張。dead zone の幅と virtual reference level が**二つの設定値の間**として定義されている
- **量か二値か**: **層で分かれる**。定義自体は二値だが帰結は連続量（"far apart" なら飽和、無制御領域の幅が差で決まる）。McClelland & Mansell 2019 は "somewhat differing" / "reasonably similar" / "disagree sharply" と三段階に量化
- **見つからなかった**: **差を数量化した関係式・図**。Powers 2011 が conflict の深刻さの連続パラメータとして挙げるのは差ではなく **loop gain**。未取得 2 本（McClelland 2004 IJHCS / **2014「Cycles of Conflict」Sociological Theory** = conflict escalation の計算モデル論文なので**数量化がそこにある可能性は排除できない**）

## 対人関係心理にも独立に 4 つの別名で存在

- **dyadic closeness discrepancy**（Frost & LeBlanc 2022, JSPR）—— `|ideal_A − ideal_B|` を明示的に計算。"taking the **absolute value of the difference** between the two partners' ... ideal IOS ratings"
- **couple desire discrepancy**（Willoughby et al. 2014）
- **sexual desire discrepancy**（Jodouin et al. 2021）—— `|A−B|` を連続量として運用、絶対値版と符号付き版が並存
- **objective value congruence**（Dale et al. 2018）—— 上司と部下の価値基準の差の絶対値を二乗し、**非線形性まで検定**

**該当なしで確定**: Carver & Scheier 1982（Psych Bulletin 全文通読。ただし**1998 年の書籍は未取得で「無い」とは言えない**）、Fletcher & Simpson の Ideal Standards Model（全文 grep 0 件）。

## それでも空いている場所が 2 つ（ここが本日いちばん使える）

1. **「差が大きいと結合できない」を論じた先行は、まだ見つかっていない。** 既存研究はすべて**すでに結合済みのペア**（交際中・既婚・既存の上司部下）を対象に、差と満足度・distress・role stress の**相関**を見ている。**差が関係の成立可否を決めるという形になっていない**
2. **非単調性（最適な差がゼロでない）が、観測範囲のどこにも無い。** PCT も対人関係心理も組織心理も**すべて単調で「差ゼロが最善」**。Orton & Weick 1990 が二値だったために差分が立ったのと同じ構図が、ここでは**単調 vs 非単調**の軸で立つ

## 書くなら応答が要求されるもの

- **実証 3 件が独立に否定的**: Frost & LeBlanc は null（信頼区間が 0 を含む）、Willoughby は統制変数扱い、Baucom et al. 1996 は "differences between spouses' standards were **somewhat less related** to marital functioning"（後 2 件は二次資料止まり・未確認）。**効いていたのは一貫して各人の内部不一致（actual vs 自分の ideal）のほう**
- **方法論上の地雷**: 組織心理では Edwards の difference score 批判以降、**差を単一スカラーに畳むこと自体が方法論的に否定**され、polynomial regression + response surface に置換（Edwards & Cable 2009）。**ΔT\* を 1 つの量として立てる定式化は、ここへの応答も要る**

## 適用範囲の制約（原典に明記あり）

McClelland 自身が「設定値の差」は**共有変数が存在するときにしか定義されない**と書いている —— 統制対象が完全に異なる場合は "**it makes no sense to compare their reference values**"。**二者がそもそも別のものを気にしているとき、Δ(T_n\*, T_m\*) は定義されない。**

観測論の注意も原典にある: "The outside observer **can see only the actions of the individuals involved, not their reference values** ... **small disagreements in reference value typically lead to wide disparities in output**"。**差はペアの構造的性質だが直接観測できず、行動出力からの推定は系統的にバイアスがかかる。**
