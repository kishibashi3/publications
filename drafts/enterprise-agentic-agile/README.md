# Enterprise Agentic Agile（EAA）

> 位置づけ：案内（非規範）
> 対象：Cellの責務分割とFederation。
> 参照：定義元は[Core](core.md)と[Profiles](profiles.md)。

単独で成立する[AA](../agentic-agile/README.md)から、責務の分割とFederationによって拡張する仕組み。
Cellの自律性を保ち、内部方式の異なる開発主体とも協働する。

## 読む順序

初めて読む場合は、考え方と開発の姿、原則・仕様、必要な適用例の順に読む。
運用中に仕様を確認する場合はCoreとProfilesを直接参照する。

| 段階 | 文書 | 位置づけ |
| --- | --- | --- |
| 1. 考え方と開発の姿 | [導入解説](development-model.md) | AAからの拡張、分割とFederationの理由、具体例。非規範 |
| 2. 原則・仕様 | [Core](core.md) | 責務と分割、自治、意味と合意、変更、成果と記録 |
| 2. 原則・仕様 | [Profiles](profiles.md) | 責務仕様、引受・改訂・解除、Standard／Domain |
| 3. 詳細解説・適用例 | [Delivery Guide](delivery-guide.md) | GitHub・記録・運営の選択例。非規範 |
| 3. 詳細解説・適用例 | [Role Model](role-model.md) | 適用ガイドの役割編。非規範 |
| 3. 詳細解説・適用例 | [Adoption Guide](adoption-guide.md) | 導入・役割移行の例。非規範 |

CoreとProfilesが仕様の定義元であり、解説・適用ガイドは新たな義務を追加しない。
これらは草案である。詳細スキーマやFederationの状態遷移は未確定で、今回のAA Principlesの採用は、EAA仕様の承認・採用を意味しない。
