## AA・EAAの文書構成

| 文書群 | 対象 | 入口 |
| --- | --- | --- |
| Agentic Agile（AA） | 一つのAgentic Cell内部の判断・実行・検証・学習 | [AA](agentic-agile/README.md) |
| Enterprise Agentic Agile（EAA） | Cellの責務分割・自律性・Cell間の相互作用 | [EAA](enterprise-agentic-agile/README.md) |
| 自己改訂規範アーキテクチャ | 規範の所有・改訂・版参照という共通基盤 | [共通規範](self-revising-norm-architecture/README.md) |

AAとEAAは扱う境界が異なる。AAはCell内部の実行原則、EAAはCellの分割と接続を扱う。
一つのAgentic Cellで全責務を担う構成では両者が重なる。EAAに参加するすべてのCellへAAを要求するわけではない。

この案内は文書の配置を示すもので、規範の準拠先や採用版を変更しない。
その他の下書きは、このディレクトリ直下の各原稿を参照する。
