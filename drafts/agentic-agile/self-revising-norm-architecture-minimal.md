# 自己改訂規範アーキテクチャ v1

2026-09-19 · Kazuhiro

本書は規範の体系の根である。根は小さいほどよい。ここには、改訂の循環を回すのに要るものだけを置く。道具の決めごとと、後回しにしたものの一覧は、下の層に置く。

## 1. 規範文書が持つもの

| 項目 | 内容 |
| --- | --- |
| 所有者 | 誰が変更を承認するか。人間とする |
| 観測 | 見直しの根拠として何を記録するか |
| 準拠先 | 従う上位の規範文書と、その版 |

## 2. 改訂

- 評価・改訂の提起・採否を、追記のみの記録に残す
- 所有者が承認した改訂を、新しい版とする
- 改訂を提起した者は、その改訂を承認しない
- 版は改訂ごとに増える識別子とし、大小の順序以外の意味を持たない

## 3. 参照

- 規範文書は、準拠先を版を明示して参照する
- 参照は下位から上位への一方向とし、上位の規範文書は下位を参照しない
- 上位の版が上がっても、下位は自動では追随しない。下位が旧版を指している間は、下位の記述に従う

## 4. 根

本書は体系の根である。本書の版は所有者の承認そのものによって成立し、その手続きは本書の外にある。本書 v1 は所有者が承認済みである。第1章から第3章は、本書の内側の規範文書に適用する。
