# CHANGELOG — AIエージェント設計概論

## 2026-09-20

### 「創発 × 自律」の成立条件を追記（第5章・第7章）
- 第5章に「『創発 × 自律』を成立させる5つの構造条件」を追加 — 事前リスク判定 / 事後構造チェック（幅の上限を含む） / ループ上限 / 連鎖上限 / 不可逆操作の隔離
- 事前リスク判定の前提を明記：人間に回すべき操作は事前に列挙できる。列挙したものをルールで人間側へ倒し、残りは自律で回す
- 第5章に「5条件が変えるのはスペクトラム上の位置」を追加 — 創発は二値、連続するのは「解の形を事前にどこまで固定できるか」。形が既定の帯をガードレール付き自律に移す。構造の追加には上限があることを明記。協働ハブ運用でも同じ5条件が現れることを追加事例として記載
- 第5章の連鎖上限を「文脈の汚染の時間軸版」から「汚染とは逆向きの失敗 — 汚染を止める文脈分離がドリフトを生む」に書き換え
- 第7章に「安全弁は品質保証ではない」を追加 — 安全弁と品質保証を混ぜない。安全弁に判断を持たせると安全弁自体が壊れる
- 第7章に「事後チェックは『複数の独立軸』で構成する」を追加 — 文脈バイアスは役割分離で補正できるがモデルバイアスは補正できない
- 第7章に「止められる範囲でしか止められない」を追加 — 取り消せない操作は実行そのものを承認に通す
- 第7章の安定性チェックリストに5項目追加（事前リスク判定 / 事後チェックの軸の独立性 / 上限が推論に依存しないこと / 検証側の帯域 / 不可逆操作の承認）
- 根拠: colaboration-agent での実地検証（issue #9）
