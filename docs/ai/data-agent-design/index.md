# データエージェント設計

> **データ層の正しさと、エージェントのコンテキスト制約は、別の関心である。**

---

## 📚 目次

### [第1章：データエージェントの設計 ― 正しさとサイズの分離](./chapter-01.ja.md)
意味的に正しい Gold レイヤーは、エージェントのコンテキストに対して大きすぎる。Platinum という**実行時ウィンドウ**を Gold の横に開き、**zero sync**（同期しないから壊れない）の一時投影として answer を返す設計を示す

---

## 🎯 このシリーズの目的

AI エージェントがデータを扱うときに直面する構造的な問題を整理する。

「賢い検索」や「リアルタイム分析」ではなく、
**「意味の保存」と「サイズ制約」をどう両立するか**を設計の軸に置く。

- エージェントへのデータ渡しで「なぜか壊れる」を経験した人
