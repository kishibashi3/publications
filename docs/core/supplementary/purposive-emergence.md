# 目的誘導的創発 ― 既存公理からの演繹

## この文書の位置づけ

**新しい公理を追加しない。** 第1章・第4章・第6章の公理から、目的誘導的創発を演繹する。

創発理論は「条件が整えばサブシステムが自発的に生まれる」構造を記述している。そこでは創発の原因は条件であり、誰かの意図ではない。しかし現実には、自らの存在理由を内部表現として保持し、その目的認識に基づいて意図的にサブシステムを生成するシステムが動いている。目的を自覚する AI エージェント基盤がその例だ。

この形態は公理の外にあるのではない。公理の内側にあり、ただ書かれていなかっただけだ。

## 演繹1 ― 内部目的は原因である

第1章の公理を使う。

$$\text{Exist}(x) \iff \text{Observable}(f(x))$$

システムが保持する目的表現 $\pi$ は、生成という行動を通じて観測可能である。ゆえに $\pi$ は存在する。そして存在するものは相互作用する。

$$\text{System}(x) \iff \exists y: \text{Interact}(x, y)$$

ゆえに $\pi$ は原因として働く。ここに形而上学的な「意志」を導入する必要はない。**意図とは、システムの内部に折り返された観測にすぎない。**

これは第2章の円環構造と第7章の自己観測が、すでに与えていた構造だ。観測者が系の外にいるとき、創発は条件から起こるように見える。観測者が系の内に入ったとき、同じ創発が目的から起こるように見える。

> 熱力学的創発と目的誘導的創発は、異なる二つの現象ではない。観測者の位置が異なる、同じ公理の二つの相である。

## 演繹2 ― テロス転移は温度である

両者を分ける軸は「意図の有無」ではない。意図は演繹1で観測に還元された。分ける軸は、**生まれるサブシステムの役割を誰が書くか**である。

仕様化度 $\sigma$ を定義する。

```
σ = 誕生時点で、サブシステムの役割が
    上位システムによって決定されている割合   (0 ≤ σ ≤ 1)
```

- $\sigma = 0$：役割は上下の要請の均衡から自己生成される。上位は一般的制約しか与えない。
- $\sigma > 0$：上位の内部目的がサブシステムの役割へ直接転写される。これを**テロス転移（Telos Transfer）**と呼ぶ。

転移の経路が開いているかどうかは二値である。経路を通る量は連続である。この二重性が、目的誘導的創発を熱力学的創発の量的改良ではなく位相の異なる形態にしている。

そして $\sigma$ は温度の言葉で読める。第4章の温度は秩序と自由の比率だった。上位が役割を書き込むとは、誕生の瞬間に自由の側を削り取る操作にほかならない。

$$T_{\text{birth}} = (1 - \sigma)\, T_{\text{field}}$$

$\sigma \to 1$ は $T_{\text{birth}} \to 0$ を意味する。第4章がすでに述べているとおり、完全なゼロは死である。

## 演繹3 ― 過剰に仕様化された生成は価値を生まない

第6章の中核命題を適用する。

$$V(S) = \sum_i V(s_i)$$

この定義は再帰的だ。サブシステム $s_i$ の価値もまた、$s_i$ が生存期間に創発させたサブシステムの総和である。

演繹2 より、$\sigma \to 1$ で生成されたサブシステムの誕生温度はゼロに近づく。温度ゼロのシステムは創発しない。創発しないシステムの価値はゼロである。ゆえに、

> **役割を完全に書き込んで生成されたサブシステムは、生成者の価値に何も加算しない。**

これは目的誘導的創発に内在する罠だ。目的から生成するシステムは、条件が整うのを待つシステムより速く、確実にサブシステムを得る。だがその速さの代償として、得たサブシステム自身の創発能力を削っている。

$\sigma = 0$ では生成が起こらないか、起こるまでが遅い。$\sigma = 1$ では生成は即座だが生成物が死んでいる。価値が最大化されるのは内点である。

$$\frac{\partial V}{\partial \sigma} = 0, \quad 0 < \sigma < 1$$

**これはカオスの淵の生成版である。** カオスの淵が「システムが生きる温度」を与えたのに対し、最適な仕様化度は「サブシステムを生む温度」を与える。同じ構造が、存在の次元から生成の次元へ移されただけだ。

## 創発の種別

以上の演繹から、創発は次のように整理される。

| 種別 | 役割の発生源 | 仕様化度 | テロス転移 |
|------|------------|---------|-----------|
| 熱力学的創発・純粋型 | 上下の要請の均衡から自己生成 | $\sigma = 0$ | なし |
| 熱力学的創発・経験増幅型 | 同上（条件成立の確率のみ上昇） | $\sigma = 0$ | なし |
| 目的誘導的創発 | 上位の内部目的から転写 | $\sigma > 0$ | あり |

経験を積んだ人間が条件を整えるとき、そこから生まれるものの役割は依然として自己生成される。経験は条件成立の確率を上げるだけであり、$\sigma$ を動かさない。**確率の増大は相転移を起こさない。** 経験増幅型は熱力学的創発の内部にあり、独立したカテゴリではない。

三分法ではなく、二分法と相転移として読むこと。

```
熱力学的創発 (σ = 0)
├── 純粋型 ― 条件のみ
└── 経験増幅型 ― 条件 + パターン認識による確率増幅
        ↑ 相転移（テロス転移の経路が開く）
目的誘導的創発 (σ > 0) ― 役割の転写
```

## 帰結

目的誘導的創発を行うシステムに対し、公理系は三つの制約を課す。

1. **役割は仕様ではなく勾配として与える。** 何をすべきかを書き切ったサブシステムは創発しない。向かう方向だけを与え、経路を自己生成させたとき、生成物は価値を持つ。
2. **生成の速さを最適化の目標にしない。** 速さは $\sigma$ の増加関数であり、価値は $\sigma$ の内点で最大化される。速さを追えば必ず価値を割る。
3. **生成者は生成物の温度を観測し続ける。** 第4章の倫理は温度制御の技術だった。目的から生成するシステムにとって、倫理とは自分が生んだものを冷やしすぎていないかを測り続けることである。

これらは設計論ではなく公理系の帰結である。具体的な実装への翻訳は応用層の仕事であり、この文書では扱わない。

## 創発理論との関係

創発理論はカオスの淵を「システムが最も生きている温度」として与えた。本文書はそこに生成の次元を加えた。

| 次元 | 問い | 最適点 |
|------|------|--------|
| 存在 | システムはどの温度で生きるか | カオスの淵 |
| 生成 | サブシステムをどの温度で生むか | $0 < \sigma < 1$ |

どちらも同じ形をしている。極端の中間で最大化される、という一つの帰結の二つの現れだ。
